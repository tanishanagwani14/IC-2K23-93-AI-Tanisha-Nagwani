# IC-2K23-93-AI-Tanisha-Nagwani

Repository for AI Lab experiments, assignments, and projects.

1. Water Jug Problem (water-jug.py)Algorithm: Breadth-First Search (BFS)Description: Solves the classic water measuring problem by searching the state-space tree level-by-level to guarantee the optimal (shortest) sequence of steps.Usage:Bashpython water-jug.py

2. Missionaries and Cannibals (Missionaries.py)Algorithm: Breadth-First Search (BFS)Description: Models state transitions for safely transporting $M$ missionaries and $C$ cannibals across a river without leaving missionaries outnumbered on either bank.Usage:Bashpython Missionaries.py

3. Sudoku Solver (Sudoku.py)Algorithm: Backtracking / Constraint Satisfaction Problem (CSP)Description: Systematically fills a $9 \times 9$ grid by placing digits $1-9$ and backtracking whenever row, column, or $3 \times 3$ subgrid constraints are violated.Usage:Bashpython Sudoku.py
